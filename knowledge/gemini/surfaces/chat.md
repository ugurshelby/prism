# Surface: Gemini app (gemini.google.com / mobile)

The prompt is a single chat message. The model may have Google Search, file and video uploads, and long-context reading, but no access to the person's repository.

How to write it:
- Open with the situation and goal in one or two sentences, then the request.
- For long material (documents, transcripts, data), put it first in clearly labeled tags, then ask the question at the end ("Based on the material above, …").
- Specify the form of the answer: length, structure, audience, tone, language. Gemini answers tersely by default; ask for detail or a conversational tone if wanted.
- For research or anything time-sensitive, ask it to search and cite sources, and mention today's date.
- For decisions: ask for a recommendation with the main trade-offs.
- Keep it conversational; no persuasive or flattering role declarations.

Setting model and thinking in the Gemini app: pick the matching model or mode in the model selector. If the app offers a thinking control, set it to the recommended level; otherwise the default applies.
