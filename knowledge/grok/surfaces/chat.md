# Surface: Grok chat (grok.com, Grok apps, X)

The prompt is a single chat message. The Grok app has real-time web and X search, file uploads and connectors (GitHub is in the catalog); assume no repository access unless the person connected it. [s:x-ai-grok, grok-faq, grok-connectors]

How to write it:
- Specify the form of the answer: length, structure, audience, tone. [s:xai-best-practices]
- For anything time-sensitive, ask it to search and mention today's date. [s:xai-best-practices]

Setting model and effort: the Grok app lets you switch modes for search and reasoning; pick the mode closest to the recommended level. [s:x-ai-grok]
