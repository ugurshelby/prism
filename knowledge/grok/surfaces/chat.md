# Surface: Grok chat (grok.com, Grok apps, X)

The prompt is a single chat message. The app may have web and X search and file uploads, but no access to the person's repository. [unverified]

How to write it:
- Open with the situation and goal in one or two sentences, then the request. [unverified]
- Put long material the person provides in labeled tags or fenced blocks before the question. [unverified]
- Specify the form of the answer: length, structure, audience, tone. [s:xai-best-practices]
- For anything time-sensitive, ask it to search and mention today's date. [s:xai-best-practices]
- Keep it conversational; a simple question stays a simple message. [unverified]

Setting model and effort: pick the model in the app's selector; if it offers a reasoning mode, choose the one closest to the recommended level. [unverified]
