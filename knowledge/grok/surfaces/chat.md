# Surface: Grok chat (grok.com, Grok apps, X)

The prompt is a single chat message. The model may have web and X search and file uploads, but no access to the person's repository.

How to write it:
- Open with the situation and goal in one or two sentences, then the request.
- Put material the person provides (pasted text, notes, data) in clearly labeled tags or fenced blocks, before the question when it is long.
- Specify the form of the answer: length, structure, audience, tone, language.
- For research or anything time-sensitive, ask it to search and cite sources, and mention today's date.
- For decisions: ask for a recommendation with the main trade-offs.
- Keep it conversational.

Setting model and effort in Grok chat: pick the model in the model selector. If the app offers a thinking / reasoning mode, choose the one closest to the recommended level; otherwise the default applies.
