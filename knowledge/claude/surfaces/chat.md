# Surface: claude.ai / Claude Desktop chat

The prompt is a single chat message. The app may have web search, file uploads and artifacts, but no access to the person's repository. [unverified]

How to write it:
- Open with the situation and goal in one or two sentences, then the request. [unverified]
- Put long material the person provides in labeled tags before the question. [s:claude-best-practices]
- Specify the form of the answer: length, structure (prose, list, table), audience, tone. [s:claude-best-practices]
- For decisions: a recommendation with the main trade-offs, not an exhaustive survey, unless the person wants a survey. [unverified]
- For time-sensitive questions, ask it to search and give today's date. [unverified]
- Keep it conversational; "You are…" lines add little in chat, and a simple question stays a simple message. [unverified]

Setting model and effort: pick the model in the selector; if the app offers a thinking or effort control, use the recommended level. [unverified]
