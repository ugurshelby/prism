# Surface: ChatGPT

The prompt is a single chat message in ChatGPT. Chat can use web search, attached files, images and connected sources; codebase work belongs in Codex. [s:chatgpt-prompting, chatgpt-models-help]

How to write it:
- Start with the result you want, then add only the context, output format and boundaries that change the answer. [s:chatgpt-prompting]
- Attach or paste only the material that matters and say what ChatGPT should take from each source. [s:chatgpt-prompting]
- Specify the form of the answer: length, structure, audience, tone. GPT-6 leans to long, formatted answers; ask plainly for prose or brevity when wanted. [s:openai-latest-model]
- If the person wants a direct answer rather than questions, say "make reasonable assumptions and state them briefly". [s:openai-latest-model]
- For decisions: a recommendation with the main trade-offs, not an exhaustive survey. [s:chatgpt-prompting]
- Keep it conversational; a simple question stays a simple message. [s:chatgpt-prompting]

Setting model and effort: in Chat, select GPT-6 and use the Thinking slider: Instant, Medium, High, Extra High (GPT-6 Sol) or Pro (GPT-6 Astra); options depend on plan. Terra is not available in Chat; GPT-6.1 Sol and Terra are Work/Codex options. [s:chatgpt-models-help]
