# Surface: ChatGPT

The prompt is a single chat message in ChatGPT. The app may have web search and file uploads, but no access to the person's repository. [unverified]

How to write it:
- Open with the situation and goal in one or two sentences, then the request. [unverified]
- Put long material the person provides in labeled tags or fenced blocks before the question. [unverified]
- Specify the form of the answer: length, structure, audience, tone. GPT-6 leans to long, formatted answers; ask plainly for prose or brevity when wanted. [s:openai-latest-model]
- If the person wants a direct answer rather than questions, say "make reasonable assumptions and state them briefly". [s:openai-latest-model]
- For decisions: a recommendation with the main trade-offs, not an exhaustive survey. [unverified]
- Keep it conversational; a simple question stays a simple message. [unverified]

Setting model and effort: pick the model in the selector; if the app offers a thinking control, use the level closest to the recommendation. ChatGPT picker labels were not verifiable from public docs. [unverified]
