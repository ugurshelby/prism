# Surface: ChatGPT

The prompt is a single chat message in ChatGPT. The model may have web search, file uploads and other tools, but no access to the person's repository.

How to write it:
- Open with the situation and goal in one or two sentences, then the request.
- Put material the person provides (pasted text, notes, data) in clearly labeled tags or fenced blocks, before the question when it is long.
- Specify the form of the answer: length, structure, audience, tone, language. GPT-6 defaults to long, heavily formatted answers; if the person wants prose or something short, say so plainly.
- If the person wants a direct answer rather than clarifying questions, say "make reasonable assumptions and state them briefly".
- For decisions: ask for a recommendation with the main trade-offs, not an exhaustive survey.
- For research or anything time-sensitive, ask it to search and cite current sources, and mention today's date if relevant.
- Keep it conversational; role declarations add little in chat.

Setting model and effort in ChatGPT: pick the model in the model selector. If the app offers a thinking / reasoning control, set it to the level closest to the recommended effort; otherwise the default applies.
